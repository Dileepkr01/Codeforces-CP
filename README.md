My 31-Day Competitive Programming Challenge using
the TLE Eliminators CP-31 Sheet.

## 🎯 Goals

- Complete all 31 problems rated 800.
- Solve one problem every day.
- Write solutions in Java.
- Practice problem-solving and logical thinking.
- Improve implementation speed and accuracy.
- Maintain daily consistency.

## 🧠 Daily Workflow

1. Select one unsolved problem from CP-31.
2. Understand the problem and constraints.
3. Think of a solution independently.
4. Implement the solution in Java.
5. Test locally using VS Code.
6. Submit on Codeforces.
7. Push the accepted solution to GitHub.
8. Record the approach and complexity.
